1.3 Configure parameters

Configure signal processing, smoothing, and feature detection parameters below. Default values are optimized for standard SPM force curves.

  • Cutting proportion:
    What proportion of the curve at the start can we ignore for peak detection (default: 0.5). Lower values include more of the far approach region.
  • Resampling factor:
    Increases the resolution of the data grid (makes it denser) to capture more precise timing of peaks and dips (default: 5).
  • Peak Detection Criteria:
    Configures directional point counts needed to identify rupture events (how many points in a row must increase or decrease to label a point as a peak):
    • Increasing points (nups_peak):
      How many consecutive increasing data points are needed to confirm an upward trend is forming a peak (default: 10).
    • Decreasing points (ndowns_peak):
      How many consecutive decreasing data points are needed to confirm the peak has ended (default: 5).
    • Minimal peak height proportion:
      Minimum peak prominence normalized to total signal spread; helps ignore very small peaks (default: 0.05).
  • Dip Detection Criteria:
    How many points in a row must increase or decrease to label a point as a dip:
    • Increasing points (nups_dip):
      How many consecutive increasing data points are needed to confirm the dip has ended (default: 30).
    • Decreasing points (ndowns_dip):
      How many consecutive decreasing data points are needed to confirm a downward trend is forming a dip (default: 10).
  • Smoother span value for deflection:
    Fraction of points influencing local regression using lowess. Increase slightly if high-frequency noise creates false-positive rupture peaks (default: 0.0001).
  • Interpolation skip distance (delta):
    Speeds up lowess() execution across large datasets by interpolating between points spaced by delta (default: 5).
  • AFMToolkit CP multipliers:
    • Noise threshold: (default: 1).
    • Significance threshold: (default: 10).
  • Local peak windowing correction:
    When TRUE, refines peak detection by searching for the true maximum within a local window in the raw data around the smoothed LOESS peak.

2. Classification

The application evaluates curves using three independent classification models to predict event profiles (e.g., none, one rupture, double rupture, or bad curve):

  • Brute Force: Rule-based thresholding on peak counts and half-variance.
  • Classification Tree: Single decision tree trained on shakiness, deflection IQR, and deflection variance features.
  • Random Forest: Ensemble model.

2.3 Export the classification results

Export the full dataset containing individual curve features, estimated number of peaks, and predictions from all three classification models. Click the button below to save the detailed metrics as a CSV file for downstream statistical analysis.

Exported Dataset Structure: The downloaded CSV file contains individual curve metrics and prediction results:
  • curve_index: Unique numerical index assigned to the curve within the dataset batch.
  • deflection_variance_half: Deflection variance in later half of the curve.
  • deflection_iqr: Interquartile range of deflection variable.
  • shakiness: A custom metric quantifying curve fluctuation or jitter. Formally defined as the mean absolute difference (MAD) between data points separated by a lag of 5 positions.
  • number_of_peaks: Estimated number of peaks.
  • full_path: Complete relative file path of the .spm source file within the uploaded archive.
  • folder: First-level subfolder name representing the experimental condition (e.g., After, Before).
  • tree_prediction: Classification result predicted by the single Decision Tree model.
  • forrest_prediction: Classification result predicted by the Random Forest ensemble model.
  • brute_prediction: Classification result predicted by the rule-based brute force method.

3. Metric Calculation and Visual Inspection

In this chapter, classification labels from your chosen model are applied to extract quantitative mechanical properties from each Force–Distance curve. Once a target model is selected, the application computes key parameters, such as rupture force (FR) and apparent bilayer thickness (zA-C), and enables interactive visual inspection to verify or manually adjust contact points.
